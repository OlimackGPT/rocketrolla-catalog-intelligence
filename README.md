# RocketRolla Catalog Intelligence Engine

Next.js MVP for upload, analytics, valuation, partner recommendations, and reporting.

## Run locally
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:3000`

## Build
`npm run build`

## Deploy to Vercel
1. Push this repo to GitHub.
2. In Vercel, import project and select this repository.
3. Set env vars from `.env.example` as needed.
4. Deploy.

If Supabase/Gemini keys are missing, app remains in mock/local mode.
